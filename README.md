# Zadiq Arabian Meals

ملخص وثيقة مشروع: تطبيق زادك AI

زادك AI هو مساعد تغذية شخصي ذكي موجه للمستخدم العربي، يهدف إلى تحويل عملية متابعة التغذية وحساب السعرات إلى تجربة سهلة وقابلة للاستمرار، من خلال التركيز على الثقافة الغذائية العربية والحلول المرنة بدلاً من التعقيد والتغيير الجذرِي القاسي.

المشكلة والحل الأساسي

 * المشكلة: صعوبة تقدير السعرات والماكروز في الوجبات العربية التقليدية، التعقيد في التطبيقات الأجنبية، والتوقف السريع عن الحميات الغذائية.

 * الفكرة الجوهرية: "صوّر وجبتك، افهم محتواها، سجّلها، واحصل على خطة عملية تناسب هدفك وحياتك."

أبرز المزايا والخصائص الفنية

| الميزة | الوصف والمفهوم التشغيلي |

|---|---|

| تحليل الوجبات بالذكاء الاصطناعي | تحليل الصور أو الأوصاف النصية لتقدير السعرات، البروتين، الدهون، الكربوهيدرات، الألياف، والصوديوم مع مراعاة حجم الطبق وطريقة التناول. |

| التعديل والمرونة | إمكانية تعديل الأوزان والمكونات يدوياً بعد التحليل وإعادة الحساب الفوري لضمان دقة البيانات. |

| التوصيات والبدائل الذكية | تقديم اقتراحات تعديل بسيطة دون حرمان (مثل: تقليل الزيت، المشوي بدل المقلي) فور اكتشاف نسبة عالية من السعرات أو الدهون. |

| أدوات الإدخال المساعدة | ماسح الباركود (مرتبط بـ Open Food Facts)، المساعد الصوتي لتحويل الكلام لبروفايل وجبة، وسجل الوجبات المتكررة للتسجيل بنقرة واحدة. |

| التخطيط والوصفات | مولد خطط أسبوعية متكاملة مع قائمة مشتريات، ووصفات من الثلاجة تُنشئ وجبات مغذية بناءً على المكونات المتوفرة فقط. |

| المتابعة الشاملة | متتبع شرب الماء، لوحة تحكم يومية (Dashboard)، ورسوم بيانية ترصد تطور الوزن والتزام الماكروز. |

| المزامنة والتقارير | ربط مستقبلي مع التطبيقات الرياضية (Apple Health, Fitbit)، وإمكانية تصدير تقارير PDF لمشاركتها مع الأخصائي أو المدرب. |

تجربة المستخدم والهوية البصرية

 * التسجيل والربط: إعداد سريع يبدأ بتحديد الخصائص الجسدية (الطول، الوزن، النشاط) والهدف (خسارة/زيادة/محافظة)، مع تخصيص تنبيهات نهاية اليوم مشجعة.

 * التصميم البصري: واجهة عربية بالكامل (RTL) تدعم الإنجليزية والتركية. تعتمد ألواناً هادئة (الأخضر للصحة، الأزرق للماء، الأوف وايت للخلفيات) مع حواف دائرية ودعم للوضع الليلي.

 * نظام التحفيز: مكافآت، نقاط، وشارات استمرار (Streaks) لرفع معدل الالتزام وتحديد الإنجازات.

نموذج العمل والخصوصية

 * الفئة المستهدفة: الراغبون في خسارة/زيادة الوزن، الرياضيون، العائلات التي تطبخ أكلات عربية، ومستخدمو الحميات المرنة.

 * نموذج تحقيق الدخل (Freemium):

   * مجاني: تحليلات محددة، سجل أساسي، باركود، ومتتبع ماء.

   * مدفوع (Pro): تحليلات غير محدودة، خطط أسبوعية متقدمة، وصفات مخصصة، تقارير PDF، ومزامنة الساعات.

 * الأمان والخصوصية: حماية وصيانة بيانات المستخدم، التشفير الكامل، الالتزام بعدم تقديم تشخيصات طبية وإظهار النتائج كـ "تقديرات غذائية".

> الخلاصة: زادك AI ليس مجرد حاسبة سعرات، بل بيئة تغذية ذكية متكاملة ومصممة خصيصاً للنمط الغذائي العربي لتقديم قرارات عمليّة وسريعة لمستخدميها.
